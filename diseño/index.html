Gestión de asistencia

Control de asistencia para clases virtuales

Prepara las asistencias con anticipación, ábrelas con código QR o código manual, registra la firma de cada estudiante y cierra la sesión con un acta firmada.

  • Apertura anticipada y cierre controlado
  • Registro por QR, código manual o firma
  • Acta, reportes y historial de auditoría

Proyecto propio de gestión académica. La identidad de la Universidad Tecnológica del Chocó se usa solo como referencia visual.
